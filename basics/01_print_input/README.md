# Блок 1: Ввод и вывод данных

## О блоке
Это первый блок курса «Поколение Python» на Stepik. Здесь я изучила основы работы с данными в Python: как выводить информацию на экран, как получать её от пользователя и как хранить в переменных.

## Пройденные темы

### 1. Введение
- История языка Python
- Сильные и слабые стороны Python
- Python 2 vs Python 3
- Установка Python на компьютер
- Установка VS Code

### 2. Вывод данных, команда `print()`
- Как выводить текст и числа
- Необязательные параметры `sep` и `end`
- Множественное присваивание
- Стандарт PEP 8
- Комментарии в коде

### 3. Ввод данных, команда `input()`
- Как получать данные от пользователя
- Преобразование строки в число (`int()`)

### 4. Переменные
- Объявление переменных
- Типы данных: `int`, `str`
- Правила именования (нижнее подчёркивание, без пробелов)

### 5. Целочисленный тип данных
- Преобразование строки к целому числу
- Операции над целыми числами: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Обработка цифр числа (остаток от деления, целочисленное деление)

### 6. Частые ошибки
- ❌ Не заключайте переменные в кавычки в `print()`
- ❌ Не забывайте круглые скобки у `input()`
- ✅ Всегда используйте `int()` при вводе чисел
