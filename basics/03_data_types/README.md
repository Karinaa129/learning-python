# Блок 3: Типы данных

## О блоке
Здесь я изучаю основные типы данных в Python: числа (`int`, `float`), строки (`str`) и модуль `math`.

## Пройденные темы

### 6.1 Числовые типы данных: int, float
- Целые числа (`int`)
- Вещественные числа (`float`)
- Встроенные функции `max()`, `min()`, `abs()`

### 6.2 Строковый тип данных
- Строки (`str`)
- Функции `len()`, `str()`
- Конкатенация строк (`+`)
- Умножение строки на число (`*`)
- Оператор `in`

### 6.3 Модуль math
- Подключение модуля `math`
- Функции `sqrt()`, `ceil()`, `floor()`
- Константы `pi`, `e`
