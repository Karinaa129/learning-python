# Блок 5: Строковый тип данных

## О блоке
Здесь я углублённо изучаю строки в Python: индексацию, срезы, методы, форматирование и особенности работы в памяти.

## Пройденные темы

### 9.1 Индексация
- Доступ к символам по индексу
- Отрицательные индексы

### 9.2 Срезы
- Получение подстрок
- Срез с шагом

### 9.3–9.5 Методы строк (Части 1, 2, 3)
- Изменение регистра (`lower`, `upper`)
- Поиск и замена (`find`, `replace`)
- Разделение и объединение (`split`, `join`)
- Очистка строк (`strip`)

### 9.6 Форматирование строк
- `format()`, f-строки

### 9.7 Строки в памяти компьютера
- Неизменяемость строк

### 9.8 Сравнение строк
- Лексикографическое сравнение
